# Label trạng thái của order_shipment hiển thị ra view

PENDING|CONFIRMED|PICKED_UP|IN_TRANSIT|OUT_FOR_DELIVERY|DELIVERED|FAILED|RETURNED

PENDING -> Chờ xác nhận
CONFIRMED -> Chờ lấy hàng
PICKED_UP -> Đã giao cho ĐVVC
IN_TRANSIT -> Đang vận chuyển
OUT_FOR_DELIVERY -> Đang giao
DELIVERED -> Đang giao
FAILED -> Thất bại
RETURNED -> Trả hàng
