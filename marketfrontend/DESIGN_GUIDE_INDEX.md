Test code, yêu cầu chỉnh sửa nếu cần.

## 💡 Tips

1. **Càng chi tiết càng tốt**: Specify exact colors, sizes, spacing
2. **Sử dụng ảnh**: Upload screenshot để AI hiểu rõ hơn
3. **Iterate**: Yêu cầu chỉnh sửa sau khi có code đầu tiên
4. **Test responsive**: Luôn test trên mobile, tablet, desktop
5. **Follow design system**: Giữ consistency với project hiện tại

## ✅ Checklist

Trước khi yêu cầu AI thiết kế, đảm bảo bạn đã:

- [ ] Xác định mục đích của component/page

- [ ] List các features cần có
- [ ] Xác định color palette
- [ ] Xác định typography
- [ ] Xác định responsive breakpoints
- [ ] Xác định animations/interactions
- [ ] Xác định framework và libraries
